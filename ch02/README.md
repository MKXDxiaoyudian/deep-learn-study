## 这道题到底在练什么

不是练 `x1 and x2` 这种逻辑写法，而是练：

> **自己选一组 `w = (w1, w2)` 和 `b`，让 `w1*x1 + w2*x2 + b` 在四个输入上的正负号，正好符合真值表。**

答案**不唯一**：只要四个输入都满足，就是对的。`w` 决定直线的方向，`b` 决定门槛的高低（详见先读文档第 2–5 节）。

## 任务（按顺序做）

### 第 0 步：纸面练习（不写代码，约 10 分钟）

1. 在纸上画一个 2×2 表格，行是 `(x1,x2) = (0,0),(0,1),(1,0),(1,1)`；
2. 先令 `w = (0.5, 0.5)`，算 `w·x` 的四个值（0、0.5、0.5、1）；
3. 想：AND 要让前三个输出 0、最后一个输出 1，`b` 应该落在哪个区间？代进去验证。

> 卡住就看 [00-先读 §3](00-先读-w和b怎么来的.md)：AND 的每一步都写出来了。

### 第 1 步：三个门（改函数里的三个数）

打开 `exercises.py`，每个门函数里都有这一行：

```python
w1, w2, b = None, None, None   # TODO: 改成三个数
```

把它改成你算出来的三个数即可（三个门各改一次）。**运行时会打印每个输入的打分**，例如：

```
AND(0,1): 0.5*0 + 0.5*1 + (-0.7) = -0.20 -> 0
```

这样填错时你能直接看到是哪一行符号不对，而不是只看到 `AssertionError`。

| 门 | 要满足的输出 | 提示（先读文档对应节） |
|---|---|---|
| AND | 0,0,0,1 | §3：w=(0.5,0.5)，b 卡在 (-1, -0.5] |
| NAND | 1,1,1,0 | §4：把 AND 的 w、b 同时取反 |
| OR | 0,1,1,1 | §4：w=(0.5,0.5)，b 卡在 (-0.5, 0] |

### 第 2 步：XOR（两层组合）

实现 `XOR`：**只允许用 `AND`/`NAND`/`OR` 组合**。提示（先读 §6）：

```
s1 = NAND(x1, x2)
s2 = OR(x1, x2)
y  = AND(s1, s2)
```

### 第 3 步：`perceptron_fit`（拓展题）

书中第 2 章**没有**讲感知机学习算法（原书 §2.3 说参数由人决定）；这一题是拓展：给数据，让算法自己学 `w`、`b`。

- 标签必须是 **+1 / -1**（不是 0/1）；
- 只在**误分类点**上更新：`w ← w + lr*y*x`，`b ← b + lr*y`；
- 一轮没有更新就提前 `break`（收敛）；
- 伪代码见 `exercises.py` 的 docstring，推导见先读 §7。

## 卡住时看哪里

| 症状 | 去看 |

## 验收（全过 = 完成）

1. `AND/NAND/OR` 真值表全对；
2. `XOR` 真值表全对；
3. 运行时打印的每一行 `AND/NAND/OR(...)` 里，打分 `w·x+b` 的正负与输出都符合预期；
4. `perceptron_fit` 在 `two_blobs` 上准确率 ≥ 0.98。
